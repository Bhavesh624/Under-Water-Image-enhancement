# Under-Water-Image-enhancement
Developed a transformer-based UWFormer model with multi-scale attention and semi-supervised learning, outperforming CNN-based methods on benchmark datasets, with potential for real-time marine and surveillance applications.
Achieved PSNR 22.35, SSIM 0.8565 on UIEB dataset (800 samples), performing competitively with UWFormer (PSNR 23.23, SSIM 0.903 on 8000 samples), demonstrating strong efficiency with limited data.
